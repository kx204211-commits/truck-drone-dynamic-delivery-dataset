# 动态组批车机协同配送算例

本仓库存放《滚动时域下多车多无人机动态组批协同配送优化》的主算例及Java补充实验数据，供算例核对和相关研究使用。目前公开数据与场景说明，算法代码暂不公开。

[下载数据](RHDBC_public_dataset_20261008.zip)，解压后按 `scenario_index.csv` 查找所需实例。

## 数据内容

| 目录或文件 | 内容 |
|---|---|
| `data/base/` | 50单主算例及配套禁飞区域 |
| `data/java_v29_scale/` | 50、75、100、150、200、300单，每种规模10组，共60个实例 |
| `data/java_v29_stress/` | 五类扰动、四档参数、四种规模、10组重复，共800个场景 |
| `scenario_index.csv` | 实例路径、随机种子与资源配置 |
| `scenario_parameters.json` | 配送中心、时域及车机物理参数 |
| `DATA_DICTIONARY.md` | 字段含义与单位 |
| `PROVENANCE.md` | 数据说明与版本记录 |

表中目录及校验文件 `checksums.sha256` 位于压缩包内。场景索引、参数和说明文件也单独放在仓库中，便于查看。

## 场景设置

| 因素 | 四档参数 |
|---|---|
| 到达集中度 | 1、1.25、1.5、2 |
| 车辆可用比例 | 1、0.8、0.6、0.4 |
| 空间收缩系数 | 1、0.75、0.5、0.25 |
| 拥堵波动参数 | 0、0.5、1、1.5 |
| 无人机可用比例 | 1、0.75、0.5、0.25 |

到达集中度通过压缩订单到达时刻的分布调整，订单总量不变，时间窗同步平移。空间收缩系数越小，订单越集中。基准按每5单配置1辆卡车、每车4架无人机设置；资源不足时的离线增配情况见场景索引。

## 使用说明

算例为上海典型配送场景下的仿真数据，需求、服务等级、到达时间及时间窗按实验设定构造，部分经过可行性调整。禁飞区域采用模型中的圆形区域设定。

时间单位为分钟，距离为公里，需求为千克。`deadline`用于服务评价，硬时间窗以 `hardEarly` 和 `hardLate` 为准。空间扰动后的坐标已保存在相应实例中。资源或交通参数不同的场景可能使用相同订单；交通模型只提供参数，不提供逐时道路速度矩阵。

Java扩展实例与主算例分目录保存，不作为原MATLAB目标函数图表输入的替代。仅凭本仓库数据不能完整复现算法求解结果。引用时请注明仓库地址及所用提交编号。

# RH-DBC 动态车机协同配送实验数据集

本仓库仅公开实验数据与场景说明，不包含算法源码、可执行程序、求解方案或性能结果。

> 完整数据以压缩包公开：[下载全部算例与配套说明](RHDBC_public_dataset_20261008.zip)。下载后解压即可获得下文所列的 `data/` 目录及全部文件。仓库首页另提供字段说明、场景索引和参数，便于在线阅读。本文只公开数据，不包含算法代码。

## 数据性质与适用范围

数据为基于上海典型配送场景构造的情景仿真算例，不是企业真实交易订单。主算例的位置使用具名地点；需求、服务等级、到达时间、截止时间及客户类型为实验设定属性，部分经过可行性调整。原CSV保留调整前数值及调整理由。禁飞圆形区域为模型场景设定，不是现行官方空域边界或航行依据。确切地理信息采集来源在现有文件中未单独记录，不宣称来自特定地图供应商。

主算例与配套禁飞区文件按原文件逐字节复制。Java扩展数据从已完成运行的订单快照中提取输入字段，未重新生成订单、改写时间窗或调整数据。所有配送结果字段已移除。

## 目录

- `data/base/`：50单主算例和当前配置选用的v5禁飞区域。
- `data/java_v29_scale/`：50、75、100、150、200、300单，10组种子，共60个规模实例。已逐项核验同一规模与重复下七算法输入一致，仓库只保留一份。
- `data/java_v29_stress/`：五类因素、四档水平、50/100/200/300单、10次重复，共800个场景实例。
- `scenario_index.csv`：实例与随机种子、扰动强度、名义及最终测试资源配置的对应关系。
- `scenario_parameters.json`：当前Java场景配置中的物理、时域、配送中心等参数，不含算法参数或本地路径。
- `DATA_DICTIONARY.md`：字段及单位。
- `PROVENANCE.md`：来源版本与提取范围。
- `checksums.sha256`：发布文件校验值。

## 五类因素

按Baseline、Mild、Moderate、Severe依次设置：

| 因素 | 四档参数 | 含义 |
|---|---|---|
| ArrivalRate | 1、1.25、1.5、2 | 围绕到达时刻中位数压缩到达分布；时间窗同步平移，倍数1完全保持原数据。是固定订单总量下的到达集中度变化，不能解释为随机到达过程参数估计。 |
| FleetAvailability | 1、0.8、0.6、0.4 | 基准车辆数量的可用比例。 |
| SpatialSpread | 1、0.75、0.5、0.25 | 向预设聚类中心收缩；越小表示越集中，不意味着难度越高。 |
| TrafficVolatility | 0、0.5、1、1.5 | Java交通模型的波动控制参数；订单字段可不变，参数不同。没有公开道路逐时速度矩阵，单靠订单文件不能还原完整交通过程。 |
| DroneAvailability | 1、0.75、0.5、0.25 | 每车无人机由4架减至3、2、1架，其他物理限制保持一致。 |

基准每5个订单配置1辆车，每车4架无人机；车辆数随订单规模扩展。最终资源配置来自已完成的离线增配测试，不代表理论最小车辆数，也不表示运行途中即时增加车辆。`addedDrones`包含新增车辆搭载的无人机总数。

## 使用方法与边界

依据`scenario_index.csv`选取CSV，读取订单输入，再使用对应场景参数与资源配置。部分因素只改变资源或交通参数，相同订单文件是预期现象。所有时间为运营开始后的分钟，`deadline`不等于硬截止时间，硬时间窗以`hardEarly`与`hardLate`为准。

本数据包支持获取和复核相同算例，不声称在不公开算法代码的情况下能够完整复现算法结果。Java V29扩展算例不视为原论文MATLAB图表输入的数值等价证明；本包未包含未经核验的MATLAB大规模实例。
